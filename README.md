## 🛠 Инструкция для команды (Как сдавать свою часть)

1. **Создайте скрипт** в папке `src/` (например, `student(номер студента)(индикация файлов).py`).
2. **Напишите код**, который очистит ваши данные и приведет их к Единому стандарту (см. ниже).
3. 📤 **ЗАГРУЗИТЕ** получившийся чистый `.csv` файл на Гугл Диск.
4. 💻 Сделайте `git commit` и `git push` вашего **скрипта** (`.py`) на GitHub.

## 🎯 Единый стандарт данных (Золотое правило)

Чтобы мы могли на Этапе 2 успешно слить все файлы в один большой DataFrame, **ваши итоговые таблицы должны содержать ровно 11 колонок в следующем порядке и с такими же названиями:**

```python
TARGET_COLUMNS = [
    'first_name',       # Имя пассажира (латиница, верхний регистр)
    'last_name',        # Фамилия пассажира (латиница, верхний регистр)
    'birth_date',       # Дата рождения в формате YYYY-MM-DD
    'document_number',  # Номер документа (паспорта) БЕЗ пробелов
    'flight_date',      # Дата рейса в формате YYYY-MM-DD
    'flight_number',    # Номер рейса (например, SU1306NO)
    'departure',        # Аэропорт вылета (код IATA, например, SVO)
    'arrival',          # Аэропорт прилета (код IATA, например, KJA)
    'pnr',              # Код бронирования (6 символов)
    'ticket_number',    # Номер электронного билета (только цифры/буквы без пробелов)
    'ff_number'         # Номер карты лояльности (только номер, без префиксов типа FF#)
]# Spies
